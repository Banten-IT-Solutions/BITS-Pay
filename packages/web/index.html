Cara Kerja

Empat langkah mudah untuk menerima pembayaran QRIS

1

Buat Akun

Daftar gratis, buat workspace dan app. Dapatkan API key.

2

Create Charge

Panggil API untuk membuat transaksi dengan amount dan order_id.

3

QRIS Dinamis

Dapatkan QRIS dinamis dengan kode unik. Pelanggan scan dan bayar.

4

Auto Confirm

Upload bukti transfer, OCR verifikasi nominal. Transaksi auto-confirm.
