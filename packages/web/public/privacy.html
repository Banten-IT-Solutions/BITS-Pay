1. Data yang Kami Kumpulkan

BITS Pay mengumpulkan data yang kamu berikan saat mendaftar dan memakai layanan:

  • Identitas akun: nama, email, dan (opsional) nomor telepon.
  • Data aplikasi & integrasi: workspace, nama app, callback_url, dan API key kamu.
  • Data transaksi: jumlah, order_id, status pembayaran QRIS, dan bukti transfer yang kamu unggah untuk verifikasi OCR.
  • Data langganan & invoice: tier, periode bayar, dan riwayat invoice.
  • Log teknis: alamat IP, waktu akses, dan endpoint yang dipanggil, untuk keamanan & audit.

2. Bagaimana Kami Memakai Data

  • Menjalankan layanan: membuat payment, verifikasi OCR, mengirim callback/webhook ke callback_url milikmu.
  • Memproses langganan premium dan invoice.
  • Keamanan: mencegah penyalahgunaan, rate-limit, dan audit log.
  • Kepatuhan hukum bila diwajibkan.

Kami tidak menjual data pribadimu ke pihak ketiga.

3. Penyimpanan & Keamanan

Data disimpan di infrastruktur Cloudflare (D1/SQLite). Password di-hash (bcrypt), API key di-hash (SHA-256). Kami menerapkan enkripsi dan akses terbatas untuk melindungi data.

4. Bukti Transfer (OCR)

Bukti transfer yang kamu unggah untuk verifikasi pembayaran digunakan untuk konfirmasi OCR dan disimpan sesuai PROOF_RETENTION_DAYS.

5. Cookie & Local Storage

Dashboard memakai token JWT yang disimpan di localStorage browser kamu untuk sesi login. Landing tidak memakai cookie pelacak pihak ketiga.

6. Hak Anda

Kamu dapat mengakses dan memperbarui data melalui dashboard, meminta penghapusan data, atau menghubungi kami via email di bawah.
